# WZD 亚马逊公司管理｜经营评估底座

本项目用于支持 CEO 对亚马逊电商业务的决策。五个岗位各自提供专业评估；涉及多个岗位的事项，先形成各岗位判断，再汇总为一份决策建议。

## 当前状态

CEO 已撤回此前提供的具体经营信息与扩张方案，旧内容不得作为公司事实。此后重新提供的信息：CEO 从 2015 年 7 月开始做亚马逊，2015–2017 年亲自负责多项业务，2017 年起组建并培训运营团队，2018–2019 年逐步转向全面管理；当前团队约 30–31 人、已列岗位合计 29 人，人数均待核对。欧洲与美国业务各有一位运营主管。CEO 希望团队长期持续发展，以公司整体盈利为底线，全年总销售额同比增长 10%；部分财务口径待明确。具体见 [CEO 决策画像](CEO决策画像.md)。具体站点、履约模式、产品、店铺与财务现状仍未知。

CEO 于 2014 年毕业于电子科技大学，曾在意法半导体担任约一年工艺工程师，随后受妻子分享的亚马逊工作经历启发而离职创业。运营招聘标准从早期重能力且可接受大专学历，逐步提高为近两三年通常看重一本或较好二本背景；能力或业绩突出者可破格。

新补充的经营经历：2017 年从深圳回南宁组建团队；2017–2018 年人员留任不稳，2019 年后出现稳定核心员工，2020 年后业绩和团队扩大，2022–2024 年人员流动下降。仓库在 2024 年由深圳搬至南宁；当前发货经广州转中欧班列去欧洲或走海运去美国。搬仓初期约 60–80 箱/日，目前估计约 100 箱/日、每月约 26 个发货日。上述均为 CEO 自述，具体经营和物流账单待核实。

## 使用方式

1. 描述想法、目标、适用站点、涉及产品和预期时间；未知的内容可以留空。
2. 岗位负责人先判断“建议推进 / 小范围验证 / 暂缓 / 不建议”，再说明依据、风险、所需资源、验证动作和停止条件。
3. 涉及平台规则、税务、劳动法规、认证或知识产权的结论，应先核对适用地区与最新可靠资料。
4. 任何金额、转化率、销量或交期预测，都必须标明数据来源、口径和假设；不得把假设写成公司事实。
