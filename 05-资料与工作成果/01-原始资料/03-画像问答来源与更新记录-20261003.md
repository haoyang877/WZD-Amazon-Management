正文事实与规则只在对应画像维护，此处提供问题、变化与去向。画像采用“原问题 → 回答摘要 → 画像判断或更新 → 待澄清”的结构，摘要不是逐字转录。CEO 的个人评价、经验成功率、财务估计和法规理解均保留自述性质；没有将助手分析、拟议任命或未来预算写成已经执行的制度。

## 3. 与旧画像的关系及尚未解决的口径

| 信息关系 | 本次处理 |
| --- | --- |
| 反感新品早放弃与允许止损 | 保留“反感草率放弃”的背景，补充经过尝试仍无效可退出；仍需观察期起点和审批人 |
| 温和留人与可能调整小组人员 | 保留一般毛利 KPI 未达标的温和管理；持续亏损且无改善能力、意愿是另一场景，不能混成统一不处罚或自动解聘制度 |
| 主管权限大与运营推广自主 | 同时保留两种描述，标明重大动作阈值和审批分界尚未确认 |
| 美工一个人与外部兼职 | 全职编制仍一人，新增兼职支持说明，不能把兼职直接加入 31 人 |
| 新增两个店铺与旧 13 店基线 | 统计日与是否已经包含不明确，维持原数量待核，不擅自算成 15 店 |
| 采购归属原先未知 | 更新为仓库兼管执行；采购批准、付款与供应商承诺权限仍待核 |
| 月度支出与固定成本 | 保留 CEO 给出的 150–200 万元总额，明确其中采购、物流及提成不全是固定费用 |
| 两项目资金可承受与预算批准 | 记录 CEO 判断，未宣布两个项目已经批准或满足所有实施条件 |
| 普通环节可定位责任与跨部门追责缺失 | 分别记录质检交接的责任定位和需求、毛利判断的追责缺口 |
| 法律底线与平台规则 | 记录两者现状差异；本轮没有确认整改制度，也没有把经验中的费率、税务要求写成普遍规则 |
