# 产品运营小组独立仓库入口

产品运营小组的现有流程、判断经验、角色说明和产品交付已于2026-10-08迁入独立私有仓库：[Amazon-Product-Operations](https://github.com/haoyang877/Amazon-Product-Operations)。当前维护分支为main。

新仓库向WZD的同一编辑协作者发送了邀请，接受邀请后可访问并编辑。后续小组内容在独立仓库维护，本目录只保留迁移入口；既往副本仍可通过WZD仓库的Git历史查看。

公司层面的职责与协作仍引用[亚马逊运营管理流程框架](../../../03-共同工作流程/11-亚马逊运营管理流程框架.md)及相关公司文档。迁移没有改变实际任命、预算或经营授权。
