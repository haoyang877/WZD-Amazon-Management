## 1. 改版主线

七张分别回答：**产品长什么样 → 放在家中是什么感觉 → 尺寸是否合适 → 真人游戏时的实际关系 → 真实结构细节 → 图案如何表达个人风格 → 使用者看到的键鼠空间。**

避免“同一张俯视桌面换文字”以及粗圆框、大引线、大标题反复使用。变化来自机位、距离、光线、场景风格和信息功能；配色、图案、文字层级保持统一。场景只使用已有证据支持的办公/居家办公和游戏，不用学习、绘画或餐桌来凑数量。

## 3. 去重硬检查

生成前按矩阵锁定视角，生成后在七图缩略总览中检查：

1. **02/04/06不得出现同一个桌面机位。** 02左前远景、04右后肩侧真人、06短边对角近景。至少机位、距离、光线、主体布局三项明显不同。
2. **07不得复用02或04完整主场景。** 不把原暖木桌和原游戏桌换圆框当作新增图片；07必须重新呈现第一人称操作关系。
3. **场景风格有明确区别。** 自然居家、成人游戏、现代个性工作台、操作局部各有用途；不只是背景换色。
4. **05与06不能再堆大圆框。** 局部窗口最多一个、引线细短；没有结构必要时不用框。03的3mm窗口只服务尺寸。
5. **01/03是受控例外。** 01轻斜产品照、03正交信息图，功能与版式不同；03保持准确，不追求夸张角度。
6. 不为完成7张而引入产品没有的功能、赠品、尺寸、用途或未证实效果。

## 4. 图案、事实和版式统一

### 产品事实

- 900×400×3mm以用户确认和内部产品表为依据；只有900版进入本套。
- 原版武士、月亮、建筑、山体和红/粉植物的主要位置与构图必须保留，不重新画一个“相似武士”。透视可变化，图案不能随场景变化。
- 缝边按实拍可见结构展示，Gummibasis依据内部橡胶属性；背纹、线色、针距和包边不能由模型自由补造。
- 不使用水滴、擦拭功效、无味图标、自然橡胶采集素材、永不褪色/永不脱线、竞技精度等未经验证内容。
- 图片05的真实细节和03的厚度窗口要以实拍/尺量作校对；生成后仍是视觉样稿，不是功能测试证据。

### 版式与可读性

- 全套一种主要无衬线字体、固定标题和正文层级；06若使用另一展示字体，必须有明确整套设计目的，不随机切换。
- 只用本品红/黑/灰加中性背景色。环境可暖/冷变化，但不把产品印色随环境大幅改成另一版本。
- 副图通常一个标题加一行辅助信息。标题不占超过画面约1/6，避免粗犷大字压缩产品；不把短图文塞成Listing五点。
- 细引线、细边框、克制留白，不将大圆与高饱和粗框当作每张图的固定结构。
- 02/04/06/07存在键鼠/其他配件时，按实际画面注明未包含配件；说明字号和对比应在手机缩略展示中能读，不能藏在画面角落。
- 键鼠不能悬空、重复、变形或明显比例不对；04/07的手部姿态、指头、握鼠关系和键盘位置需逐一初审。
