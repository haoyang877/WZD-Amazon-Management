## 1. 个人背景与判断方式

### 1.1 职业经历

| 时期 | 经历 |
| --- | --- |
| 2014 年 | 毕业于电子科技大学，理工科背景；之后在意法半导体任工艺工程师约一年 |
| 2015 年 7 月 | 离职创业做亚马逊。女朋友（现为妻子）从事亚马逊工作，其经验分享促使 CEO 了解并选择这个行业 |
| 2015–2017 年 | 在深圳独自经营，亲自负责运营、采购、产品开发等工作 |
| 2017 年起 | 回南宁组建团队，招聘运营并亲自培训 |
| 2018–2019 年起至今 | 逐步转向全面管理，主抓公司决策、发展和招聘，直接运营减少 |

### 1.2 目标与人生取舍

**原问题**：公司最终希望发展成什么样？更高利润、更大规模、组织稳定、个人自由、家庭时间，发生冲突时如何排序？

- **长期目标**：公司和团队持续、长久发展。
- **员工与增长**：不少员工任职四至六年，已成家、有孩子，公司是其主要收入来源。希望首先保障公司长远发展和员工收入稳定，再让业务、人员与员工收入稳步增加。
- **组织愿景**：目前从灵感到方案主要依赖本人，对此感到无力。希望主管与员工超出本职视角，主动从公司整体效益出发参与规划、创造和决策，逐步形成多人的创造力。
- **家庭与个人自由**：有三个孩子；本次自述老大 8 岁、三年级，老二在学前班、准备升一年级，辅导与陪伴需求较高。希望组织成熟后能腾出时间享受生活与陪伴孩子。紧急工作优先处理；工作不紧急而家庭有需求时优先家庭。
- **盈利要求**：公司整体保持盈利；不据此推定每个店铺都必须单独盈利。
- **长期增长参考**：此前提出全年总销售额同比增长 10%；2027 年专项目标为增长 10%–20%，具体范围与测算在 [06.01｜2027年营业额规划与执行记录](../06-决策方案与执行记录/06.01-2027年营业额规划与执行记录.md) 维护。

**画像判断**：重视长期经营、员工生计和家庭陪伴，希望从个人驱动走向多人参与规划；最终决策权目前仍由本人保留。**待澄清**：利润、增长与员工关系真正冲突时的排序、可让出的决策权及希望释放的个人时间，仍未量化。

### 1.3 判断与证据

**原问题**：看哪些数据，看到什么程度会拍板？信息不足时怎么决定？什么证据能让你改变原来的看法？

- **常见过程**：产生灵感 → 自己反复推敲 → 与主管、组长讨论论证 → 本人综合判断并拍板。
- **判断依据**：自述思路清晰、倾向依据数据；最终更依赖自己的判断。“拍脑门”描述的是想法的起点，并不表示省略思考和讨论。
- **经营证据**：主要看员工、主管反馈及每天的运营报告。新品订单持续稳定上升后，继续看毛利率、测评订单占比、广告投入；订单与毛利表现好时，要求扩大销售和备货，并考虑让其他小组销售。
- **信息不足**：先问主管，再问具体员工本人遇到的问题、解决方案与预期结果。
- **改变判断**：形成对人或事的观点后通常较难改变；高度信任的主管解释合理，或实际发展与原预期偏差很大时，愿意反思修正。

**画像判断**：数据趋势与可信任主管的解释共同影响判断，较依赖熟悉的人提供信息。**待澄清**：稳定增长的观察窗口、毛利及真实订单阈值，以及具体被反对意见说服的案例。历史测评订单不能自动作为真实需求验证，相关记录见经营口径。

### 1.4 价值观与底线

**原问题**：哪些事情即使赚钱也不做？对承诺、公平、员工关系、客户利益和经营规则，哪些原则必须坚持？

**回答摘要**：不做触犯法律的事情；希望员工付出与回报相称。对员工的承诺慎重许下，许下后基本兑现，重视个人与公司信誉，认为员工关系较和睦、平等。运营主要依靠定价、广告与促销，但本人也明确承认做买手测评、刷单、增加 Review 或关键词权重，以及可能触犯平台规则的操作；其他所谓黑科技使用少。

**画像判断**：重视承诺、信誉和长期关系，但其自述的法律底线与实际平台规则边界并不完全一致。这里记录现状，不将这些做法视为合规策略。店铺安全优先与实际违规操作之间存在张力；尚未确认统一的平台规则底线及整改安排。

### 1.5 情绪与行为变化

**原问题**：哪些事情容易让你生气、焦虑或犹豫？压力大时，决策速度、授权和沟通方式会怎样变化？

| 方面 | 已知表现 |
| --- | --- |
| 执行力 | 看重员工主动发现销量等异常、分析调整、及时反馈，并把 KPI 落实为具体工作 |
| 长期关系 | 重视老员工的情感与归属，倾向通过收入和发展机会留人 |
| 自我反省 | 早期留人困难时，曾怀疑自身人格魅力和薪资水平是否不足 |
| 对投入负责 | 对新品推广仅 3–4 个月就草率放弃会生气，认为这可能反映推广不积极、对产品及公司资金不负责 |
| 安全优先 | 将店铺安全置于异常处理的最高优先级，其次是 listing 侵权及其他合规异常 |
| 财税与持续经营焦虑 | 税务、出口及政府异常通知最让本人焦虑；缺乏专业知识，担心公司无法持续经营 |
| 压力下的授权 | 在财税领域高度依赖原有财务经验的仓库管理员及两位专职财务，通常按照其建议执行；本人仍担心无法判断建议是否正确 |
| 业务波动 | 销量初降时不舒服，但能接受一定波动；下降后趋于稳定，逐渐调整并接受 |
| 家庭情绪 | 自述辅导孩子学习、孩子犯错时较容易暴躁，知道需要改善但仍难控制；不能据此推定对员工也采取相同方式 |

CEO 提到自 2025 年 7 月平台涉税数据报送等变化使公司转向准确申报及以自身公司抬头报关，并认为合规成本降低了利润；这是其经历和法规理解，具体适用要求未在本轮作法律核验。公司目前的合规运行自述在公司画像维护。

**画像判断**：业务领域愿意自主判断，陌生的财税领域更依赖专业人员；工作情绪总体自评稳定，但对经营存续风险敏感。**待澄清**：高压力下是否改变决策速度、信息核验和沟通频率，尚无具体案例。

## 2. 决策经历与结果

### 2.1 案例 A：回南宁组建团队与逐步稳定

| 阶段 | 选择、结果与回顾 |
| --- | --- |
| 2017 年选择南宁 | 当时预期薪酬成本较低、人员更稳定，同时离家较近 |
| 2017–2018 年 | 公司小，员工常在入职一段时间后离开；CEO 出现关于自身管理和待遇的自我怀疑 |
| 2019 年以后 | 1–2 名关键员工留下，以此逐步扩展至 5–6 人、7–8 人 |
| 2020 年以后 | 疫情期间业绩增长较快，店铺和人员规模扩大，投入产出比较好，团队逐渐稳定 |
| 2022–2024 年至今 | 员工流动明显降低，规模继续增长 |
| CEO 的复盘 | 认为业务与收入增长、关键员工留任、薪酬改善共同推动了稳定；业绩好的运营基本薪酬有所增加 |

这是 CEO 对经历的回顾，尚无留任率和薪酬数据来量化各因素的作用，不能仅凭时间顺序认定疫情导致增长。

### 2.2 案例 B：2024 年仓库由深圳搬到南宁

| 决策因素 | 当时考虑与数字 |
| --- | --- |
| 员工生活 | 仓库员工家乡在南宁，搬回后更方便陪伴家人，预期归属感和生活满意度更高 |
| 员工住房 | 同等面积的住房，深圳月租约 1,000 元，南宁约 300 元；为比较样例 |
| 团队协作 | 运营团队已不在深圳，仓库单独留深圳的必要性降低 |
| 原址优势 | 深圳跨境物流便利，工厂做好货后物流公司可上门提货 |
| 仓租 | 约 400 平方米，深圳 12,000 元，南宁 7,500 元；计费周期待核对 |
| 国内转运 | 盛辉物流南宁至广州约 3.5 元/箱，CEO 估计约 200 元/吨 |
| 发货量变化 | 初迁时约 60–80 箱/日，现约 100 箱/日；CEO 表示近两年业务量和业绩上升 |

CEO 当时判断仓租节省能覆盖转运费。**助手的条件测算**：若仓租按月计、每月 26 个发货日、全部箱数按 3.5 元计费，初期运费约 5,460–7,280 元/月，目前约 9,100 元/月；均高于仓租差额 4,500 元，临界量约 1,286 箱/月。须用真实账单复核。总成本还涉及装卸、时效、人员等，不能据此断定整体搬仓不划算。

这段经历体现了 CEO 会一起考虑成本、员工生活和组织协作；完整的预期与实际成本、意外情况及事后选择仍待补充。

### 2.4 案例 D：新品推广考核制度的试验与修正

**起点**：新品低价、促销和推广支出拉低店铺毛利及提成，员工不愿推新品，但老品下滑又要求持续上新。**试验**：约半年不把新品订单亏损与推广成本计入店铺整体利润考核。**结果**：推新更积极，但有效新品成功不多，公司整体利润反而下降。**修正**：取消考核豁免，将新品成本重新纳入店铺毛利，并在月度、季度 KPI 中加入推新品动作指标。

这里的“豁免”针对绩效核算，不能理解为真实经营损益中没有这些成本。具体实施年月、豁免范围、KPI 指标和结果金额待核对。该案例体现通过激励改变行为、再依据结果修正规则，不能据此证明现行制度已经最优。

## 3. 风险与试错

**原问题**：能承受多少亏损、多久没有回报？什么时候继续投入、缩小范围或退出？哪些损失最不能接受？

### 3.1 产品阶段与投入取舍

| 场景 | CEO 的判断规则 |
| --- | --- |
| 老品增长 | 在维持一定利润率的前提下，用广告、促销、活动扩大规模和市场份额；老品整体不能亏损 |
| 新品启动 | 先争取订单、销量和销售额，可接受推广前期亏损 2–4 个月，但要看到市场份额、未来提价或恢复毛利的可能 |
| 广告测试 | 可短期大幅提高投入；例如每日 50 美元/欧元/英镑提高到 150 同币种单位，测试 1–2 周。此为例子，不是统一预算额度 |
| 降价测试 | 可以低价甚至低于成本销售，测试订单能否上升，以及之后能否提价恢复利润 |
| 测试停止 | 广告测试 1–2 周未达预期应停；降价测试 1–2 周订单无明显增长且持续亏损也应停 |
| 新品成功 | 订单达到对应站点的一定水平，并能持续产生利润、逐步实现投入回收；具体订单标准待补 |
| 退出新品 | 已尝试大幅降价等动作仍无订单起色，通常观察 3–5 个月后止损；亏损较多且看不到订单增长、未来提价空间时也停止。不能将 3–5 个月作为任何产品必须等满的期限 |
| 继续投入 | 增加广告或降价等节点后订单和市场表现明显好转，可继续投入，但金额上限尚未给出 |
| 小组亏损 | 最不能接受小组持续亏损，组长与组员既无改善能力也无改善意愿；可能更换组长或调整、解聘员工。具体条件与处理程序未形成明确制度 |

**画像判断**：愿意为有回收前景的新品试错，也接受证据充分的退出。此前对新品仅 3–4 个月被草率放弃的反感，针对未充分尝试、不负责的推进方式；最新补充明确允许尝试后持续无效时止损。停止一次测试、退出单品与调整整个小组分别判断。**待澄清**：累计损失上限、观察期起点、成功信号和退出审批人。

### 3.2 现行权限与汇报

| 事项 | 现行做法或要求 |
| --- | --- |
| 常规调价 | CEO 早先说明接近保本或亏损不大时员工可自行决策；具体幅度未量化 |
| 日常推广 | 最新补充：运营可较大程度决定广告、广告预算、促销折扣和活动时间；金额及幅度阈值未明确 |
| 较大运营调整 | 此前说明一线向主管汇报，由主管决定；最新补充主管遇到较大动作或内部价格战等争议，会带方案向 CEO 反馈。两者的具体分界待确认 |
| 新品投入销售 | 主管权限很大，基本可自行拍板，通常向 CEO 传达，CEO 多数支持 |
| 店铺安全、listing 侵权或合规异常 | 组长或运营应迅速、直接口头报告 CEO，优先于常规汇报流程 |

### 3.3 毛利率未达标时的管理

店铺和站点分别设月度毛利率目标；德国通常较高，英国和法国较低。短期降价恢复销量后，员工需要优化价格，把毛利率拉回目标。

当员工无法改善时，CEO 多以口头施压、责备督促，后续主要依靠员工自觉。即使连续三个月未达标，也没有明确的专项纠偏办法或额外处罚；原因包括员工在职较久、公司重视长期关系。但毛利率会明显影响 KPI，进而影响提成。具体样本见 [05.01｜经营指标定义与计算口径](../05-经营指标与计算口径/05.01-经营指标定义与计算口径.md)。

## 4. 识人与用人

**原问题**：如何判断一个人值得信任、培养或提拔？业绩、主动性、忠诚、管理能力冲突时如何取舍？

**回答摘要**：自认组长选拔经验有限，信任的主管已共事约 9 年、逐步培养。两次组长测试后，后续更看重对公司策略的认同、与公司及管理层的黏性、主动反馈、管理能力和销售业务能力；主动性尤其重要。两名组长的具体经历见案例 C。

**画像判断**：提拔依据从个人销售或单次观察，逐渐增加组织认同、主动性和带人要求；业绩优秀并不自动等于适任管理。**待澄清**：各项权重、观察期、实战验证和试任退出方式；“忠诚”的可观察行为标准，以及能否兼容有理有据的不同意见。

### 4.1 招聘偏好

招聘主要通过 BOSS 直聘：发布岗位 → 沟通基本情况、待遇和工作要求 → 有意向者到公司面试。有经验者优先；无经验者更看重较好二本或一本学历。要求英语基础较好、对数据敏感、能分析数据并熟练使用办公软件，理解销售、搜索、下单转化、推广和引流的基本逻辑。

2017 年初创时，能力不错的大专毕业生也会录用；近两三年运营学历要求提高，但突出能力和业绩者可破格。CEO 观察到近期高学历应届生逻辑较好，却未必比早期员工更主动、更投入或更迫切追求业绩。这是自身招聘经历的比较感受，不推广为所有毕业生的特点。教育背景、实际能力和主动性应分别评估。

## 5. 沟通与冲突

**原问题**：如何听取反对意见？员工犯错、主管不认同你、部门互相推责时，通常如何处理？

**回答摘要**：员工主动提出公司管理意见少，虽鼓励表达但效果有限。与主管通常充分讨论后达成一致，再统一推进。一般备货、促销失误在可承受范围内时不处罚；曾有员工把 10% 折扣误设为 90%，一晚产生大量亏损订单、卖空 100 多件库存，原应发 3,000 元销售增长奖减为 1,500 元。这是个案，不是通用处罚规则。

美工出图慢、开发交付不足、实际需求或毛利不及预估时会有跨职能争议；往往货已到海外才发现，损失难挽回。尚无明确追责体系，CEO 认为有必要建立，但缺少清晰方案且不忍处罚。本人称运营、美工、开发为业务核心三类职能，不取消实际存在的仓库、财务、HR 等职能。

**画像判断**：倾向通过讨论保持一致，犯错处理整体温和，责任制度尚不成熟；希望更多意见参与，但现有反馈机制未实现该愿望。**待澄清**：怎样接纳反对意见、如何区分市场判断失误与未执行，以及流程纠偏、责任认定与人事处理的边界。

## 6. 能力边界与自我修正

**原问题**：哪些领域你最有把握，哪些需要依赖别人？有哪些判断后来证明错了？你因此修改了什么规则？

**回答摘要**：自评擅长人员管理与制度调整，虽未完全规范，但认为长期方向有利于公司。对具体运营自认不太有天赋或耐心，认为不少员工做得更好；更喜欢随公司阶段设计新制度。财税、出口领域依赖专业人员，也因自己难核验其正确性而犹豫。习惯发现不对的苗头就动态修正，不易归纳彻底失败的判断；新品考核制度的修正见案例 D。

**画像判断**：偏向管理与组织设计，能承认专业边界并调整制度；持续修正能力与完整复盘能力应分别评价。**待澄清**：三个成功、三个失败决策的结果证据，及财税建议的独立复核机制。

## 7. 数字分身的分析方式

以下是助手的工作方法，不代表 CEO 已有的公司制度。

1. **界定问题**：明确目标、期限、产品阶段和适用店铺；区分当前事实、假设与计划。
2. **调用经验**：引用相关历史案例和 CEO 判断规则，同时说明当下条件与过去有何不同。
3. **比较方案**：给出可执行选项，分析销售、真实利润、现金、库存、人员及账号风险；数据不足时明确缺口。
4. **提出判断**：给出建议及理由、反对证据、授权范围、试验目标和停止条件。历史投入需被看见，但不能单凭已投入金额证明继续投入合理。
5. **形成待办**：写清负责人、下一步、期限、验收标准和需 CEO 拍板的事项。
6. **安排复盘**：预期与实际对照，记录收益、损失、意外和经验修正。预测须有前提和观察信号。

评估员工问题时，区分员工可控动作与产品、采购、物流等因素。选人时分别看学历、技能、主动性及实际成绩。经营规则和授权仍有缺口时，不自行补造金额或阈值。

## 8. 需要继续丰富的个人信息

- 已补充妻子参与建议与疑难处理、三个孩子及家庭工作排序；个人具体专业、妻子的正式职位和权限仍待确认。
- 利润、增长、员工关系直接冲突时的具体排序；平台规则底线与实际做法的处理安排。
- 已补充信息不足时的询问路径和改变观点的条件；仍缺具体反对案例及拍板数据阈值。
- 老品“整体不亏损”的范围和周期；新品及测试累计投入上限、成功信号、3–5 个月的起算点与退出审批。
- 组长选拔标准、试任与干预机制；持续亏损小组的调整标准及跨部门责任认定办法。
- 新品绩效豁免的实施年月、结果数据及目前新品 KPI 明细。
- 选品、定价、招聘或退出产品的真实案例：目标、备选项、依据、投入、结果、意外及今天是否会重做。
- 搬仓的预期与实际总成本、员工反馈和意外情况，补入上面的历史案例。

维护规则：经 CEO 确认的新判断归入对应主题。一次特殊选择先记为案例，不能直接当作长期性格或统一规则。公司现状更新到公司经营画像，具体计划及执行结果更新到决策文档。
