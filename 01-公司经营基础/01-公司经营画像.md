## 2. 定位与竞争优势

**原问题**：为什么买家选择你们？优势来自产品、价格、运营、供应链还是品牌？哪些优势可以持续？

**回答摘要**：销售普通百货商品，另有挂钩、椅子套等品类。供应商采购价、头程物流价均接近市场一般水平，定价与竞对相差不大；注册了欧洲、美国店铺商标，但品牌影响力有限。持续经营依靠平台广告和多年运营经验，选品时避开竞争白热化、缺少新卖家进入空间的产品。

**画像更新**：CEO 认为核心能力在选品策略、运营经验和适合自身的运营模式；目前未提供明显的产品、成本或品牌优势证据。**待核对**：竞品样本、获客成本、自然流量、品牌复购和优势能否由不同人员复现。

## 3. 业务与盈利结构

**原问题**：哪些站点、店铺、品类贡献销售和利润？季节性、老品下滑、退款与费用怎样影响结果？

### 3.1 站点表现与方向

以下均为 CEO 对自身经营的判断，不当作对所有卖家适用的市场结论。

| 站点 | 回答摘要与当前方向 |
| --- | --- |
| 德国 | 自述毛利率最高、销售上限较高，归因于消费能力和较低的 FBA 费用占比；费用与归因待数据验证 |
| 法国、西班牙 | 自述竞争相对较小、销售与新品推广较容易，但 FBA 费用较高、毛利偏低 |
| 意大利 | 自述 2025 年 VAT 相关保证金要求使公司停掉大部分意大利站业务，仅保留一个店铺的意大利站；保留站点销量明显增长，近期不计划重启其他意大利站。提到 5 万欧元保证金，其适用主体、日期和条件须另核，不能当作全部卖家的统一要求 |
| 英国 | 自述市场大、英语门槛低、卖家多、价格竞争强，销售较难增长 |
| 美国 | 自述近年来销售额、利润率及利润额持续下降，认为自身人员、运营及产品与竞对存在差距；考虑逐步减少投入，新增小组主要配置欧洲。是方向与计划，不是美国业务已经关闭 |

CEO 表示美国与欧洲五国都有盈利业务，未逐店提供损益，不能据此推定每店每月都盈利。

### 3.2 主要盈利品类与老品维护

| 品类或因素 | 回答摘要 |
| --- | --- |
| 窗膜 | 单向膜夏季销售与毛利率较高 |
| 防尘罩 | 竞争较小、毛利较高；CEO 提到佣金约 8%，其他产品常见 13% 或 15%。是其产品费率自述，不能直接套用到所有站点与分类 |
| 鼠标垫、皮革垫 | 9 月至次年 1 月需求较大，客单价较高，可持续贡献销售与利润 |
| 圣诞装饰 | 采购成本低、重量轻、头程费用较低，CEO 认为整体利润率可观 |
| 老品下滑 | 观察客户需求和增长较快的竞品款式，完成知识产权分析后扩展相同或相似需求的款式，用新品对冲老品下降；核查结果不能仅凭相似外观作出 |
| 退款与转化 | 部分品类退款率偏高，侵蚀毛利；CEO 观察到前台高退货率标记还会影响转化，具体链接与影响需核对 |

现行做法是将能盈利的产品跨店、跨运营销售，以扩大品类份额、比较同站点不同运营表现，并弱化对单人的依赖。**分析边界**：跨店销量须扣除内部转移；多账户与产品安排仍需具体核对平台规则。

## 5. 客户与市场认知

**原问题**：核心客户是谁、解决什么问题？客户反馈如何进入选品、产品整改和页面优化？

**回答摘要**：客户主要是各站点购买百货的终端零售消费者。售后问题来自邮件和页面评论；汇总自有及竞品评论，识别质量、使用问题与需求变化，再优化产品和页面。

**画像更新**：客户反馈是现行需求与整改线索，但还没有细分到人群、场景和客户选择原因。**待核对**：反馈整理负责人、频次、问题优先级、整改验收与退货原因分类。

## 6. 组织与人才能力

**原问题**：谁能独立经营、带人或处理异常？关键岗位依赖谁？各岗位实际工作量和接替能力如何？

**回答摘要**：运营主管能够独立经营、培训与处理紧急问题；妻子也能处理疑难问题，内部解决不了时会付费找外部服务商。优秀运营经验依赖强、培养周期长；唯一开发人员虽沉淀流程，接替仍困难。全职美工已建立团队认可与配合默契，替代不容易。

运营、开发、美工及财务工作量都较大。运营反馈日常数据、竞品、文案、图片需求与广告任务做不完；美工任务积压明显，内部效率与能力提升是 CEO 的关注点。已请外部兼职分流：速度较快、质量一般，运营更偏好全职美工；这说明已有需求缺口，但尚不能量化应招聘多少人。

**画像更新**：不仅开发，图片交付与关键运营的能力和负荷也制约扩张；已识别主管、开发和美工等关键依赖。**待核对**：两位区域主管的具体分工、各岗工时、排队与返工量、备份人员、外部服务商介入范围及权限。

## 7. 流程与协作

**原问题**：从需求提出、开发、采购到销售复盘，如何交接？哪里经常等待、返工或责任不清？

**回答摘要与现行流程**：运营提出新品需求 → 开发结合需求偏好、店铺已有品类和同质流量匹配候选 → 指标达标后采样 → 运营与开发共同确认样品 → 确定款式并采购大货 → 供应商发至南宁仓库 → 质检、贴标与发货 → 货代运输入海外仓 → 运营推广。暂时没有承接需求的候选可进入产品库，待小组需求出现后再评估；多数时候是新品不够用。

日常新老品采购需求由运营通过表格提交仓库，仓库联系供应商、兼管采购及质量沟通。等待集中在找供应商、打样寄样、共同确认和大货生产；入仓发现质量、包装尺寸或包装方式不符时，需要退回重新包装或生产，拉长周期。

**画像更新**：具体质检和交接差错通常可定位到环节；但实际需求和毛利不达预期时，开发与运营之间没有明确的最终追责机制。两种责任问题分别记录。**待核对**：立项、规格、样品、采购、付款和上市的审批人，签字标准及复盘责任；本段是现状梳理，尚未制定新的 SOP。

## 8. 财务与资源承受力

**原问题**：可用现金、库存占款、固定成本、付款周期及预算边界；同时启动几个项目还能承受？

| 项目 | 回答摘要与口径边界 |
| --- | --- |
| 对公现金 | 各店主体账户合计约 400–500 万元，CEO 认为充足；币种按上下文暂记人民币，统计日、可自由调拨部分及受限款待核 |
| 库存占款 | 约 1,000 万元，包括在途、FBA 与南宁仓库存；计价基础、滞销和跌价未给出 |
| 月度支出 | 全店约 150–200 万元，列有仓租、办公租金、工资、采购、货代、税、测评测款和提成。采购、物流和提成并非全部固定成本，不能把此总额直接当作固定费用或利润表支出 |
| 供应商账期 | 部分月结，约 45–60 天；部分现货现结，发货后立即付款 |
| 物流付款 | 当月付上月，通常签收上架后结款，自述约 45–60 天；相对发货、到账或账单的起算点待核 |
| 平台回款 | 自述亚马逊每 14 天一轮；实际可到账金额、留存与异常冻结影响未给出 |
| 新小组投入 | 单项目约 30–50 万元，CEO 判断资金上可同时启动两个；这是资源判断，不是已批准预算或现金安全线 |

新店资质审核导致估计损失约 60 万元的历史案例见 CEO 画像，不能与预计正常投入混为同一口径。**待核对**：13 周现金流、主体间资金可用性、税款与采购承诺、投入覆盖阶段、单项目损失上限及最低现金储备。月均规模与毛利定义仍以经营口径的待核项为准。

## 9. 治理与风险

**原问题**：谁能决定什么、什么需要升级？账号、供应商、产品质量和关键员工风险如何发现和应对？

**回答摘要**：CEO 最终决策；妻子与主管可提出建议。主管安排运营调整，大动作或内部价格战等争议会带方案请 CEO 判断；运营较自主决定广告、预算、促销和活动。链接侵权、封禁及店铺安全应迅速直接报告 CEO，完整权限原则见 CEO 画像。仓库监管质量、供应链与采购沟通。

| 监测事项 | 现行要求 |
| --- | --- |
| 销售变化 | 用领星 ERP 较及时观察销售增长与下降 |
| 毛利变化 | 财务每月核算一次，运营上半月、下半月各一次；运营应先发现异常 |
| 新品推广 | 前 1–2 个月每日形成日志，记录订单、Review、评级及推广操作、调整，截图发群供大家查看；测评数据需与真实需求区分 |
| 核心人员 | CEO 认为优秀运营当前较稳定，尤其依赖主管；这是观察，未提供接替或离职风险数据 |
| 财税与出口 | CEO 自述此前零申报等历史做法已逐步调整，目前基本按合规方式记账、报税和以自有公司抬头报关；曾由有财务经验的仓库管理员推动过渡，现有两名专职财务。具体合规结果未独立审计，仍会收到相关部门异常通知 |

**画像更新**：日常销售和毛利已有监测节奏，账号与财税风险需要快速升级；重大动作金额阈值、专业建议复核和退出审批尚不清晰。

## 10. 文化与学习能力

**原问题**：实际奖励哪些行为？员工是否敢反馈问题？成功经验能否复制，失败是否形成流程改进？

### 10.1 老员工激励与考勤现状

CEO 认为留人的关键是付出与回报相称。除底薪、销售提成外，现行做法包括：

- **“虚拟股权”或利润分享**：针对在职三至六年等老员工，按月或季度制定销售额、毛利润指标，达标后一次性奖励公司总盈利的一定比例。
- **销售增长奖**：本次描述为销售额连续 3 个月增长，且第 3 个月销售额增长超过 3,000 元，一次奖励 3,000 元现金。第 3 个月同比或环比、币种转换和门槛口径待核。
- **年终奖**：完成设定指标可获较高奖金，普通表现也会有表示心意的奖金；此前提到全年同比增长门槛，具体档位未给出。

CEO 自述全勤奖 100 元；每月迟到 30 分钟额度内不扣，30–100 分钟每分钟 3 元、100–150 分钟每分钟 5 元、150 分钟以上每分钟 10 元。这是其对现行制度的描述，超额或全量计费、分段方式与制度文件待核，不能直接生成薪资扣款公式。

未来新小组的提成与晋升方案见 [欧洲新小组扩张方案与执行记录](../04-经营决策与执行/02-欧洲新小组扩张方案与执行记录.md)。

### 10.2 沟通与经验沉淀

员工敢谈日常运营问题，但主动反馈公司管理意见少。美工与 CEO 沟通少、与运营沟通多，多名运营持续跟进图片进度；运营与开发产出有延迟，CEO 认为投入度较难直接判断，这属于管理感受，不能当作员工懈怠的事实证明。

单个运营或开发复用自身成功经验较有效，向全公司分享后的传递与复制效果有限；开发认可的产品也可能因运营差异无法推成。虽然有每月经验分享与 ERP 查看权限，不能据此认定方法已标准化并可复制。失败后缺少及时总结、案例收集和流程改进机制，CEO 明确认为目前不足。

**画像更新**：团队关系稳定、激励较多，但管理建议参与、跨人经验复制和失败复盘仍弱。**待核对**：培训达产率、方法实际采用率、失败原因分类及整改验证。

## 11. 能力与风险边界

- 产品开发仅一人，CEO 已确认供给不足；具体瓶颈工序与可交付量待测。
- 美工全职一人并已有外部兼职支持，需求积压明确；仍缺工时与返工数据来确定增员或流程改善的规模。
- 约 100 箱/日是现有发货量，不能直接作为仓库峰值能力。
- 老品类可能下滑，新增业务须先抵消存量下降；公司内部跨店转移不能全部计作净增长。
- 店铺与 Listing 安全是经营关键风险；异常按 [首席执行官决策画像](../02-管理角色/01-首席执行官/02-个人决策画像.md) 立即上报。
- 新组长兼管原业务的安排与容量尚未核实，具体方案在欧洲新小组扩张文档维护。
