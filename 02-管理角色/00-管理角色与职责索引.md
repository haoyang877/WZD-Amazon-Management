# 岗位职责索引

导航：[公司管理总入口与使用说明](../README.md)。

公司负责人统筹公司级判断，运营、开发、仓库、美工、财务、人力资源提供专业意见；数据支持提供共同事实。现实任职与数字会话以组织记录为准。

每个角色目录保存本角色职责和专有判断依据，跨岗位操作在共同工作流程中维护唯一版本。进入角色说明书后，按“当前公司条件 → 本岗责任 → 关联流程 → 本次任务与结果”阅读。

本页用于找到各岗位的职责、所需能力和输出要求。写法及维护方法统一见[公司管理总入口与使用说明](../README.md)第 4、8 节；实际任职、能力及负荷查[人员岗位分配与实际能力](../01-公司经营基础/03-人员岗位与实际能力.md)，会话绑定查[公司组织与角色会话对应关系](../01-公司经营基础/02-组织结构与角色会话.md)。

以上是文档导航摘要，完整职责以对应说明书为准；摘要不新增任命或授权。具体工作步骤引用跨岗位流程，当次任务和批准写入决策记录。各职责的原草案状态保持，正式生效依据仍待各实际负责人确认。

每份说明书统一包含：角色定位与边界、能力与结果、流程与接口、日常检查、公司决策参与、智能助手协作与维护。
