# 07.04｜任务验收与复盘填写模板

整体分类与填写方法见[00｜公司管理总入口与使用说明](../README.md)。

用于日常工作验收或决策文档的结果章节，原始资料放 09-原始资料与案例 并链接。关联：[04.00｜工作流程索引](../04-跨岗位工作流程/04.00-工作流程索引.md) · [06.00｜决策事项索引](../06-决策方案与执行记录/06.00-决策事项索引.md)。

## 1. 验收记录

| 项目 | 内容 |
| --- | --- |
| 对应任务、流程、角色与版本 | 待填写 |
| 现实责任人及验收人 | 待确认 |
| 原定目标、交付物与期限 | 引用批准记录 |
| 实际交付与日期 | 链接证据 |
| 过程完成情况 | 必要步骤与审核是否执行 |
| 交付质量 | 是否满足完整、正确、可使用的标准 |
| 经营结果 | 指标、期间、口径及数据来源；尚未成熟则待观察 |
| 验收结论 | 通过／需补充／返工／待观察，并说明理由 |

## 2. 复盘与改进

1. 当时条件、目标、选项、选择理由及实际投入。
2. 预期与实际差异，意外及其证据；员工可控动作和产品、供应、市场等因素分别分析。
3. 哪些经验可复用，适用条件是什么；失败原因有哪些待验证。
4. 改进任务、现实负责人、期限及验证标准。
5. 今天是否仍会这样决定；哪些新信息会改变结论。
6. 需要更新哪份画像、角色或流程；权限、预算、考核变化的批准人及状态。
