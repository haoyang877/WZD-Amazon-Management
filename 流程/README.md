# 工作流程目录

这里维护跨岗位工作的唯一流程版本。角色说明书写本岗责任和交付，操作与交接在本目录维护；各岗位共同使用一条流程。2026-10-04 建立的首批流程均为初始草案，待现实负责人细化、试跑和 CEO 审核，不视为已全面实施。

关联：[总览](../README.md) · [组织映射](../组织/公司组织架构与角色会话映射.md) · [人岗能力](../组织/人岗分配与当前能力.md) · [流程模板](../模板/工作流程卡模板.md) · [验收模板](../模板/任务验收与复盘模板.md)。

| --- | --- | --- | --- |
| [公司决策讨论与任务分派](公司决策讨论与任务分派.md) | CEO | 各方评估、分歧、CEO 决定及可验收任务 | 初始草案，0.1；生效待确认 |
| [运营计划与KPI复盘](运营计划与KPI复盘.md) | 运营主管 | 分站点计划、行动任务、审批记录与结果复盘 | 初始草案，0.1；生效待确认 |
| [新品开发到上市](新品开发到上市.md) | 产品开发管理 | 可被运营、仓库和美工接收的上市资料及交接确认 | 初始草案，0.1；生效待确认 |
| [新品推广与退出评估](新品推广与退出评估.md) | 运营主管 | 推广记录、试验结果与继续、调整或退出建议 | 初始草案，0.1；生效待确认 |

| [重大经营异常处理](重大经营异常处理.md) | CEO协调，异常来源岗位负责事实报告 | 异常事实、响应负责人、批准动作及关闭证据 | 初始草案，0.1；生效待确认 |

负责人填写真实执行人、输入、交付、接收及批准要求，记录耗时与例外。草案、试行、正式分别注明状态；修改交待内容、依据、受影响岗位、验证办法及审批。流程新增时登记本表并链接相关角色，同一操作不在多份角色手册复制。

日常记录按对应表格保存，公司级决定在决策目录；只创建已有工作需要的流程。模板和标题不构成现实授权，AI 建议、部门确认和实际执行须区分。
